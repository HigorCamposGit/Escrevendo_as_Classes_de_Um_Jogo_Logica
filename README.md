# Escrevendo_as_Classes_de_Um_Jogo_Logica.
# Desafio DIO: Escrevendo as classes de um Jogo

Projeto desenvolvido para o bootcamp da Digital Innovation One (DIO).

## 📌 Objetivo
Criar uma classe genérica que represente um herói de uma aventura e que possua as propriedades `nome`, `idade` e `tipo`, além de um método `atacar`.

## 🛠️ Tecnologias Utilizadas
- JavaScript
- Conceitos de Programação Orientada a Objetos (Classes e Objetos)
- Estruturas condicionais (`if / else`)

## 🚀 Como executar
Basta ter o Node.js instalado e executar o comando no terminal:
`node index.js`
